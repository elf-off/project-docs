# Внедрение: Время в админке по Москве (UTC+3)

## Что изменилось

### `templates/admin.html`

Добавлена JS-функция `toMoscow(utcString, opts)` -- конвертирует UTC-строку из БД
в московское время (Europe/Moscow). Автоматически добавляет суффикс `Z` к строке
из БД, чтобы браузер корректно интерпретировал её как UTC.

Функция применена в 4 местах:

| Место | Что отображается |
|---|---|
| `getTokenStatus()` | Время истечения токена в таблице аккаунтов |
| `renderLogs()` | Время событий в разделе "Логи" |
| `renderCards()` | Дата создания карточки в разделе "Карточки" |
| `showDialog()` | Время сообщений в модалке диалога |

## Проверка после деплоя

1. Открыть админку `/admin`
2. Раздел "Аккаунты" -- время токена должно показывать MSK (UTC+3)
3. Раздел "Логи" -- время событий по Москве
4. Раздел "Карточки" -- дата создания по Москве
5. Нажать "Показать диалог" на карточке -- время сообщений по Москве
6. Время в футере ("Сервер: ...") уже было по Москве, не менялось
