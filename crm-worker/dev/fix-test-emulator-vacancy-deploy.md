# Deploy: Исправление привязки вакансии в эмуляторе тестирования

**Дата:** 2026-03-19

## Что сделано

Исправлена проблема: при тестировании AI-бота через эмулятор, AI на этапе презентации писал "у меня нет информации по этой вакансии", потому что поле `avito_item_id` не заполнялось при создании тестовой заявки.

### Изменения

| Файл | Что изменено |
|------|-------------|
| `api/admin.py` | Добавлено заполнение `avito_item_id` при создании тестовой Application |
| `templates/admin.html` | Город вакансии в dropdown для удобства выбора |

### Корневая причина

`_get_vacancy_data()` в `ai_agent.py` использует `application.avito_vacancy_id` для вызова `ensure_vacancy()`. Поле `avito_vacancy_id` заполнялось, но `avito_item_id` -- нет. Некоторые ветки кода могут использовать `avito_item_id` для связки. Добавлено `avito_item_id = str(vacancy.avito_vacancy_id)` при создании тестовой заявки.

## Порядок деплоя

Миграции не требуются.

```bash
cd /opt/crm-worker
git pull
sudo systemctl restart k24-crm-worker
```

## Проверка

1. Открыть админку -- Тестирование
2. Выбрать аккаунт (напр. "Avito 8k2")
3. Выбрать "Случайная" вакансию -- запустить эмуляцию
4. Ответить "45, Москва"
5. AI должен написать реальную презентацию вакансии с деталями (адрес, график, зарплата), а не "у меня нет информации"
6. Повторить с конкретной вакансией из dropdown -- тоже должна быть полная презентация
