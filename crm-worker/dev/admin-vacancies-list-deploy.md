# Deploy: Список вакансий в админке

**Дата:** 2026-03-19

## Что сделано

Добавлен раздел "Вакансии" в админку с таблицей, фильтрами, статистикой и детальным просмотром.

### Изменения

| Файл | Что изменено |
|------|-------------|
| `api/admin.py` | 3 новых эндпоинта: `/api/vacancies`, `/api/vacancies/stats`, `/api/vacancies/{id}` |
| `templates/admin.html` | Вкладка "Вакансии" в сайдбаре, таблица с фильтрами, модалка деталей |

### Новые API-эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/admin/api/vacancies` | Список вакансий с фильтрами (account_id, is_active, search) и пагинацией |
| GET | `/admin/api/vacancies/stats` | Статистика: всего, активных, в Qdrant, по аккаунтам |
| GET | `/admin/api/vacancies/{id}` | Полная информация о вакансии (описание, адрес, parsed-данные) |

### UI

- Шапка со статистикой (всего / активных / в Qdrant / по аккаунтам)
- Фильтры: аккаунт, статус (активные/неактивные), поиск по названию
- Таблица: название, город, профессия, зарплата, аккаунт, Qdrant, время синка, статус
- Клик по строке -- модалка с полной информацией (описание, parsed-данные, ссылка на Авито)
- Пагинация "Загрузить ещё"

## Порядок деплоя

Миграции не требуются. Только обновление кода.

### 1. Обновить код

```bash
cd /opt/crm-worker
git pull
```

### 2. Перезапустить сервис

```bash
sudo systemctl restart k24-crm-worker
```

### 3. Проверить

1. Открыть админку, перейти в раздел "Вакансии"
2. Проверить что вакансии отображаются с правильными аккаунтами
3. Фильтр по аккаунту -- показывает только вакансии выбранного
4. Поиск по названию работает
5. Статистика в шапке совпадает с реальными данными
6. Клик по вакансии -- модалка с полной информацией
