# Deploy: Убрать упоминание нерабочего времени из промптов

**Дата:** 2026-03-19

## Что сделано

Убраны все упоминания нерабочего/ночного времени из промптов AI-бота. Елена больше не говорит "сейчас нерабочее время" -- просто говорит "менеджер свяжется завтра". Добавлены явные запретительные правила в system prompt.

### Изменения

| Файл | Что изменено |
|------|-------------|
| `prompts/system.txt` | Убрано правило про ночное время, добавлены запреты на упоминание нерабочего времени |
| `prompts/booking.txt` | Убраны "нерабочее время", "ночь", добавлен запрет |
| `prompts/asks_phone.txt` | Убрано "в рабочее время" |
| `prompts/no_phone.txt` | Убрано "в рабочее время" |

### Проверено и чисто

- `services/ai_agent.py` -- хардкод-упоминаний не найдено
- Остальные промпты (`greeting.txt`, `qualification.txt`, `presentation.txt`, `alternatives.txt`, `clarify.txt`, `followup.txt`, `objection.txt`) -- чисто

## Порядок деплоя

Миграции не требуются.

```bash
cd /opt/crm-worker
git pull
sudo systemctl restart k24-crm-worker
```

## Проверка

1. Запустить эмуляцию, дойти до booking
2. Бот НЕ должен говорить "нерабочее время", "ночь", "поздно"
3. Бот должен просто сказать "менеджер свяжется завтра, когда удобно?"
