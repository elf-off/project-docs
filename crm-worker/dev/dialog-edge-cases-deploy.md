# Deploy: Обработка edge-кейсов в диалоге

Дата: 2026-03-18

## Описание

Добавлена обработка трёх edge-кейсов на этапе booking:
1. Кандидат хочет выйти "сегодня/прямо сейчас" -- бот работает ночью, менеджер звонит только завтра
2. Кандидат отказывается давать телефон / не хочет звонок -- мягкий ответ + handover с пометкой
3. Кандидат просит номер телефона компании -- мягко объясняем что номера нет, менеджер сам свяжется

## Таблица изменений

| Файл | Что изменено | Зачем |
|---|---|---|

| `prompts/booking.txt` | Заменен промпт, добавлено упоминание "завтра" | Чтобы Елена сразу говорила про завтрашний звонок |

## Новые файлы

- `prompts/no_phone.txt` -- промпт для обработки отказа от телефона
- `prompts/asks_phone.txt` -- промпт когда кандидат просит номер компании

## Новый результат сессии

- `booking_no_phone` -- кандидат записан, но отказался от телефона. Менеджер должен писать в чат Авито, а не звонить.
- `callback_slot` при этом результате = `chat_only_no_phone`

## Логика phone_action в _handle_booking_response

| phone_action | Поведение | Результат |
|---|---|---|
| `refused` | Мягкий ответ через `no_phone.txt`, завершаем сессию | handover с `booking_no_phone` |
| `asks_phone` | Мягкий отказ через `asks_phone.txt`, НЕ завершаем сессию | Остаемся в `waiting_booking`, ждём время звонка |
| `none` | Обычный парсинг callback_slot | Стандартный flow |

## Миграции БД

Не требуются. Поле `ai_sessions.result` -- VARCHAR(50), новое значение `booking_no_phone` помещается.

## Тестовые сценарии

### Сценарий 1: "Хочу сегодня начать"

- Кандидат на этапе booking пишет: "Хочу сегодня начать работать"
- Ожидание: Елена отвечает что сейчас нерабочее время, менеджер свяжется завтра утром
- Покрывается обновленными промптами system.txt + booking.txt (без отдельной логики в коде)

### Сценарий 2: "Не хочу звонок, пишите сюда"

- Кандидат на этапе waiting_booking пишет: "Не хочу звонок, пишите сюда"
- Ожидание:
  - `PHONE_REFUSAL_DETECT_PROMPT` возвращает `{"phone_action": "refused"}`
  - Елена отвечает мягко: "Хорошо, менеджер напишет в чат"
  - Создается handover с result=`booking_no_phone`
  - В Telegram-сводке: `[Zapis BEZ telefona -- pisat v chat]`
  - В админке: оранжевый label "Без телефона -- написать в чат Авито"

### Сценарий 3: "Дайте ваш номер, я сам позвоню"

- Кандидат на этапе waiting_booking пишет: "Дайте ваш номер, я сам позвоню"
- Ожидание:
  - `PHONE_REFUSAL_DETECT_PROMPT` возвращает `{"phone_action": "asks_phone"}`
  - Елена отвечает: "К сожалению, у меня нет возможности дать прямой номер. Менеджер сам свяжется с вами завтра. В какое время удобно?"
  - Сессия НЕ завершается, остаемся в `waiting_booking`
  - Ждём следующее сообщение кандидата с удобным временем

### Сценарий 4: "Какой телефон?"

- Кандидат на этапе waiting_booking пишет: "Какой у вас телефон?"
- Ожидание: аналогично сценарию 3

### Сценарий 5: "Завтра в 11 удобно" (обычный flow)

- Кандидат на этапе waiting_booking пишет: "Завтра в 11 удобно"
- Ожидание:
  - `PHONE_REFUSAL_DETECT_PROMPT` возвращает `{"phone_action": "none"}`
  - `BOOKING_PARSE_PROMPT` возвращает `{"callback_slot": "завтра в 11"}`
  - Обычный flow: подтверждение + handover с result=`booking`
