# Deploy: Исправление дубликата телефона в эмуляторе

**Дата:** 2026-03-19

## Что сделано

Исправлена 500 ошибка при повторном запуске эмуляции с тем же номером телефона. Причина: `Applicant` создавался без проверки уникальности `phone`, что приводило к `IntegrityError` (Duplicate entry).

### Изменения

| Файл | Что изменено |
|------|-------------|
| `api/admin.py` | В `emulate_application` -- поиск существующего applicant по phone перед INSERT |

### Логика

Перед созданием `Applicant` проверяется, есть ли уже запись с таким телефоном. Если есть -- используется существующий (с обновлением имени при необходимости). Аналогично тому, как это сделано в `_process_new_application` в `webhooks.py`.

## Порядок деплоя

Миграции не требуются.

```bash
cd /opt/crm-worker
git pull
sudo systemctl restart k24-crm-worker
```

## Проверка

1. Запустить эмуляцию с телефоном `+79991234567`
2. Запустить эмуляцию ещё раз с тем же телефоном
3. Не должно быть 500 ошибки -- создастся новый чат с тем же applicant
