# Интеграция с Bitrix24 CRM

`app/services/bitrix_service.py` — создаёт лиды в Bitrix24 из личных сообщений Telegram.

## Сценарий

Сотрудник в личном чате с ботом отправляет сообщение, начинающееся с `#Битрикс` (первая строка, регистронезависимо). Бот парсит контактные данные, нормализует телефон и создаёт Lead через Bitrix24 REST API.

Пример сообщения:
```
#Битрикс
Иванов Иван Иванович
+7 (999) 123-45-67
Москва
Заинтересован в вакансии оператора
```

## Пайплайн

### 1. Определение сообщения

`BitrixService.is_bitrix_message(text)` — проверяет, что **первая строка** равна `#битрикс` (после strip и lower). Вызывается в `MessageRouter` до любой другой обработки личных сообщений.

### 2. Парсинг контактных данных

Два подхода последовательно:

**Regex-парсинг** (`_parse_with_regex`):
- Ищет строку с телефоном по паттерну `[\+\d][\d\s\-\(\)]{8,}`
- Строки **до** телефона → ФИО (Фамилия Имя [Отчество])
- Первая строка **после** телефона → город
- Остальные строки → дополнительная информация

**AI-парсинг** (`_parse_with_ai`): если regex не справился (нестандартный порядок, нет явного телефона в отдельной строке), задача отдаётся Claude. Промпт просит извлечь `last_name`, `first_name`, `middle_name`, `phone`, `city`, `extra_info` и вернуть JSON.

### 3. Нормализация телефона

`_normalize_phone()`:
- Убирает всё кроме цифр и `+`
- `8XXXXXXXXXX` → `+7XXXXXXXXXX`
- Проверяет формат 11 цифр, начинающихся на 7
- Если формат не распознан → ошибка

### 4. Создание лида в Bitrix24

`_create_bitrix_lead()` — POST-запрос на `{BITRIX_WEBHOOK_URL}/crm.lead.add.json`:

```json
{
  "fields": {
    "TITLE": "Отклик из соц.сетей",
    "NAME": "Иван",
    "LAST_NAME": "Иванов",
    "SECOND_NAME": "Иванович",
    "PHONE": [{"VALUE": "+79991234567", "VALUE_TYPE": "WORK"}],
    "SOURCE_ID": "WEB",
    "ASSIGNED_BY_ID": 565282,
    "COMMENTS": "Город: Москва. Заинтересован в вакансии оператора"
  }
}
```

`ASSIGNED_BY_ID` берётся из `settings.bitrix_assigned_by_id`.

### 5. Сохранение в БД и ответ

Независимо от результата создания лида запись сохраняется в `bitrix_leads` (для истории и аудита). Пользователю отправляется сообщение об успехе или ошибке с деталями.

## Конфигурация

| Параметр .env | Назначение |
|---|---|
| `BITRIX_WEBHOOK_URL` | URL Bitrix24 REST webhook (без `/crm.lead.add.json`) |
| `BITRIX_ASSIGNED_BY_ID` | ID ответственного в Bitrix24 (по умолчанию 565282) |

Если `BITRIX_WEBHOOK_URL` не задан — возвращается ошибка "BITRIX_WEBHOOK_URL не настроен".

## Обработка ошибок

- HTTP-ошибки от Bitrix24 → сообщение пользователю с кодом и текстом ответа
- Ошибки подключения → сообщение пользователю
- Ошибки парсинга (не нашли ФИО или телефон) → сообщение с примером правильного формата
